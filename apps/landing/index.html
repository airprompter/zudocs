How the integration works

Follow a change from the prompt that was approved to the answer a customer sees.

  1. 01

    Release in AirPrompter

    Versioned triage and reply prompts carry checks and any A/B split.

  2. 02

    Load on Zudocs

    Each host verifies and applies the signed release through the Agent SDK.

  3. 03

    Answer the ticket

    The desk runs the prompt and shows the reply, version and assigned variant.

  4. 04

    See the evidence

    Checks, timing, tokens and feedback make each result inspectable.

The desk keeps the customer message and reply in front. Host rollout and SDK details are available when you open them. Read the source.
