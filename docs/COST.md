# Cost

What the demo company costs to keep, line by line, and what was deliberately not built. The numbers between the
markers are written by `npm run cost:report -- --write` (Cost Explorer, unblended, full UTC days — today excluded
because it is partial); everything below them is hand-written and explains each line. The monthly cost check
(`services/cost-check`, the third of every month at 06:00 UTC — Cost Explorer settles a day about a day late, so by
the third every day of the previous month is in; the amounts keep being refined until the bill is finalised) files the same numbers as `cost/YYYY-MM.json` in the trail bucket and puts
them as `Zudocs/Cost` metrics; the budget (`zudocs-monthly`, $30, e-mail at 100 % and
166 %, forecast at 100 %) and the anomaly monitor e-mail on their own.

**Fixed vs variable.** "Fixed" (the report's `kind`) is what bills while nothing runs: the instance-hours, the volume,
the address, the zone, the key. Everything else moves with use. With the eu-west host awake all month the fixed
line is about **$12.7**; asleep every night and woken only for sessions it is about **$2.3** plus $10.36 per
awake-month prorated by the hours awake — **a two-hour session ≈ $0.03 if you click Sleep after it**; left to the
schedule, up to $0.34 for a day awake (the `t4g.micro` $0.22 + the address $0.12) plus ≈ $0.04 of idle tickets — a
wake just after the 10:40 UTC attempt runs until ten the next morning. The variable line at the idle cadence is a
few dollars; the report's projected split says which.

**Expected monthly at current usage** is the last seven full days' daily mean × 30.44 — a measurement of the week,
not a promise about the next one. The nightly sleep and demo mode move it; look at the split to see which half moved.

## The two knobs

- **Sleep / Wake the fleet (phase 8).** An EventBridge Scheduler schedule (`zudocs-eu-host-sleep`, `cron(0,20,40 10 * * ? *)`
  UTC — three idempotent attempts twenty minutes apart at ten in the morning UTC, night on both US coasts) invokes the
  power function with `sleep`; **nothing starts the host but the owner** — the desk's *Wake the fleet*, or
  `npm run host:wake -- --wait`. The schedule's sleep is refused while demo mode is on (a session is never stopped by a
  clock) and while the wire is cut (the rule restores it within fifteen minutes; the next of the three attempts
  sleeps — and if the last one at 10:40 is refused, the host stays awake until the next morning: click Sleep). Asleep,
  the EC2 lines fall to the volume's $0.70; the Bedrock line falls to zero for that host; the desk's status tick keeps
  the us-east row (and the seal's catalogue) alive at ~$0.
- **Demo mode (phase 8).** Idle, the eu-west workers run one inbox ticket an hour (Node) and every two hours
  (Python): 36 tickets a day. A ticket is a Nova Micro triage (~$0.00005), a Nova 2 Lite reply (~$0.001 at ~1,000
  input and 300 output tokens) and the judge — about **$0.0011 per ticket, so ≈ $0.04 a day, ≈ $1.20 a month** awake
  all month, and nothing while asleep. Before phase 8 the cadence was 10 and 20 minutes (216 tickets a day, ≈ $0.25–0.40
  a day — most of the Bedrock line). Demo mode (`/zudocs/dev/demo-mode`, written by the desk's presenter panel or
  `npm run demo:mode -- on`) drops the cadence to two and five minutes — ~1,000 tickets a day if it stayed on, ≈ $1.10 a
  day — and **lapses on its own after four hours**; the workers read the switch every minute and refuse a document
  with no expiry. The puller's demo cadence (a pull a minute instead of five) stays a deploy flag (RUNBOOK.md); the
  us-east host's five-minute status tick stays as it is — it is the seal's liveness (DEMO.md › beat 5).

## Deliberately not built

Each of these is a line that would dwarf the ones above, on a deployment that idles:

- **NAT gateways** ($0.045/h + per GB ≈ $33/month each): the eu-west host sits in a public subnet with a public
  address and a group with no inbound rule; the air-gapped host has no route out at all (gateway endpoints only,
  which are free).
- **Interface (PrivateLink) endpoints** (~$7.30/month each; SSM alone wants three): the hosts reach SSM, S3 and
  DynamoDB over the internet or gateway endpoints.
- **An Application Load Balancer** (~$16/month): the desk API is an HTTP API with a JWT authorizer; the sites are
  CloudFront over S3.
- **WAF** (~$8/month + rules): Cognito's lockout and the API's throttling are the defence a demo needs.
- **An Elastic IP**: nothing depends on the eu-west address; an idle EIP would bill $3.65/month while the host sleeps.
- **Spot for the daemon host**: an interruption mid-session is not worth the $2.
- **Secrets Manager** ($0.40/secret/month): the keys are SSM SecureStrings, which are free.
- **Cognito Plus, RDS, OpenSearch, Kinesis, a second availability zone**: none has a job here.
- **A GitHub Actions cost job**: it would need cloud credentials in the repository; the monthly check runs in the
  account with a role instead.
- **"Sleep N hours after a wake"**: a one-off schedule minted by the wake would need `scheduler:CreateSchedule` on
  the desk's path and a second thing to reconcile; the nightly stop bounds a forgotten host at one day ($0.34), demo
  mode bounds the model spend at four hours, and *Sleep* is one click. Revisit if a forgotten day recurs.

## Reading the numbers

```sh
AWS_PROFILE=zudocs npm run cost:report                # the tables (one Cost Explorer query, $0.01 a page)
AWS_PROFILE=zudocs npm run cost:report -- --write     # and this file's numbers section
AWS_PROFILE=zudocs aws lambda invoke --region us-east-1 --function-name zudocs-cost-check --payload '{"month":"2026-09"}' /dev/stdout   # file a month by hand (partial if still running)
AWS_PROFILE=zudocs aws s3 ls s3://<trail bucket>/cost/                                                  # the monthly documents (RETAIN; no expiry under cost/)
AWS_PROFILE=zudocs aws cloudwatch get-metric-statistics --namespace Zudocs/Cost --metric-name expectedMonthlyUsd --statistics Maximum --period 86400 --start-time … --end-time …
```

Cost Explorer settles a day about a day late; the budget's *actual* is the month to date as Budgets computes it and
can differ from the report's sum by the settling lag and tax.
